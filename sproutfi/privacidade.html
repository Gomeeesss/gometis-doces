Quem cuida dos seus dados

O SproutFi é mantido por [NOME OU EMPRESA], [CPF OU CNPJ], que é o controlador dos dados pessoais tratados no app. Contato do encarregado de dados: [E-MAIL DE CONTATO].

Quais dados coletamos

  • Dados da conta: e-mail e senha (a senha é guardada de forma criptografada pelo serviço de autenticação; nós não a vemos).
  • Dados que você cadastra: contas, cartões, transações, categorias, contas fixas, metas e orçamentos.
  • Dados técnicos: registros de acesso mantidos pelo provedor de infraestrutura, como endereço IP e data de acesso.

O app não se conecta à sua conta bancária e não pede senhas de banco.

Para que usamos

Somente para oferecer o serviço: guardar seus dados, sincronizar entre seus aparelhos, permitir login e recuperação de senha. Não vendemos seus dados e não os usamos para publicidade.

Onde os dados ficam

Os dados ficam no Supabase, provedor de banco de dados e autenticação, que pode armazená-los em servidores fora do Brasil. Cada pessoa só consegue acessar os próprios dados.

Logos dos bancos

Os logos dos bancos ficam guardados no próprio app. Nenhuma informação sua é enviada para mostrá-los.

Por quanto tempo

Enquanto sua conta existir. Ao excluir a conta, os dados são apagados na hora.

Seus direitos

Pela Lei Geral de Proteção de Dados (Lei 13.709/2018) você pode, a qualquer momento: acessar e baixar seus dados (Relatórios › Backup completo), corrigi-los no próprio app e excluir a conta com todos os dados (Minha conta › Excluir minha conta). Para outros pedidos, escreva para [E-MAIL DE CONTATO].

Cookies e armazenamento no aparelho

O app guarda no seu navegador a sessão de login e uma cópia dos seus dados para funcionar sem internet. Ao sair da conta, essa cópia é apagada.

Mudanças

Se esta política mudar, avisaremos no app.
